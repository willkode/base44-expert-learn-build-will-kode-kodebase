# AI Agent Recommender

Scan my entire Base44 app before making any recommendations.

Do not create or modify anything yet.

Your job is to analyze the app and recommend what types of AI agents would be useful inside this specific app.

Review the full app, including:

- Pages
- Components
- Entities
- User roles
- Permissions
- Workflows
- Forms
- Dashboards
- Backend functions
- Automations
- Notifications
- Admin areas
- Data relationships
- Repetitive user actions
- Repetitive admin actions
- Manual tasks that could be automated
- Places where users need guidance, suggestions, or decision support

After scanning, create a report with the following sections:

## 1. App Summary

Briefly explain what this app does, who it serves, and the main workflows you found.

## 2. Agent Opportunities

Recommend AI agents that would be useful for this app.

For each agent, include:

- Agent name
- Agent purpose
- Who uses it
- What problem it solves
- What data it needs access to
- What actions it should be allowed to perform
- What actions it should NOT be allowed to perform
- Whether it should be user-facing, admin-only, or internal/system-only

## 3. Short App-Specific Use Case Example

For each recommended agent, give one short use case example that is specific to this app.

Example format:

**Agent:** Customer Support Agent
**Use Case:** When a user submits a support ticket about a failed report, the agent reviews the ticket, checks the related report data, identifies the likely issue, drafts a suggested reply, and flags the ticket for admin review.

## 4. Recommended Priority

Rank the agents by priority:

- Must-have
- Should-have
- Could-have
- Future idea

Explain why each agent belongs in that priority level.

## 5. Suggested Agent Permissions

For each agent, recommend safe permissions.

Include:

- Read access needed
- Write access needed
- Admin access needed, if any
- Human approval required before action
- Security risks to avoid

## 6. Implementation Notes

For each agent, explain:

- What entities may need to be created
- What existing entities can be reused
- What backend functions may be needed
- What UI pages or modals may be needed
- What notifications may be needed
- What logs or audit trails should be added

## 7. Final Recommendation

End with a clear recommendation of the top 3 agents I should build first and why.

Important rules:

- Do not make changes yet.
- Do not create agents yet.
- Do not create new entities yet.
- Do not modify workflows yet.
- Only scan, analyze, and report.
- Be specific to my existing app.
- Do not give generic agent ideas unless they clearly apply to this app.
- Focus on agents that reduce manual work, improve user experience, improve admin efficiency, increase revenue, improve security, or help users get better results.
